# VolMon v2.0.0 for macOS — Low Effort Suite v2.0

**VolMon v2.0.0 (Build 20)** standardizes **VolMan** as **VolMon** across the unified **Low Effort Suite v2.0** (`PerfMon`, `EventMon`, `VolMon`, `WebMon`).

## What's New in v2.0.0
- **Unified Low Effort Suite v2.0 Branding (`VolMon`)**: Renamed to `VolMon` (`com.loweffort.volmon`) with seamless automatic migration of all existing `VolMan` v1 user preferences (`com.loweffort.volman`).
- **4-App Cross-Suite Theme & Dock Icon Synchronization**: Instant 1-click theme, custom accent color, monogram (`VM` / `VO` / `LE`), and HUD style synchronization across **PerfMon**, **EventMon**, **VolMon**, and **WebMon** (with backward-compatible support for legacy v1 installations).
- **Desktop Widget Grid Awareness**: Automatic collision avoidance across all 4 Low Effort Suite v2.0 desktop widget engines (`PerfMon`, `EventMon`, `VolMon`, `WebMon`) and macOS Notification Center widgets.
- **Full APFS & External Drive Suite**: Unified per-page Volume Switcher with already-offloaded folder guards, symlink & APFS clone deduplication, non-blocking Git & linked worktree manager, direct-streaming `.tar.gz`/`.zip` archive builder with automatic local SSD reclamation, default-off CloudStorage hydration guard, 3-column Storage Flow Map, and 8-style desktop HUD Cards.
