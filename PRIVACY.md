# Privacy Policy — VolMon for macOS

**Last Updated:** November 2026  
**Developer:** Low Effort Development Studios ([LowEffort.digital](https://loweffort.digital))

---

## 1. Local-First Volume & File Inspection

**VolMon** (`MacVolumeManager`) is a native macOS drive space analyzer, external offload planner, structured archive builder, and cache cleanup utility engineered in Swift 6 and AppKit. All volume capacity metrics, directory trees, file sizes, SHA-256 archive manifests, and cleanup candidates are inspected and processed **100% locally on your Mac**.

VolMon **never** transmits your file names, directory paths, volume serial numbers, usernames, or storage contents to any external server.

---

## 2. Zero Telemetry Capture

VolMon performs **zero telemetry capture**:
- No application launch counters, session timers, analytics SDKs, or usage tracking of any kind.
- No background beacons or telemetry headers.
- The only optional network request made by the application is checking GitHub Releases (`https://api.github.com/repos/LowEffortDigital/VolMon/releases/latest`) for software updates when **Automatically check for updates** is enabled in **Settings ➔ General**.
